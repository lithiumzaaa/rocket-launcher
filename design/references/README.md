# Design references

Target look for Rocket Launcher (a Steam redesign concept). Corner radius is deliberately smaller in
Rocket Launcher than in these shots: cards use `rounded-card` (6px).

| File | Screen | Use when building |
|---|---|---|
| `01-overview-collage.webp` | All screens together | Overall style |
| `02-home.webp` | Home: last-played hero, achievements/progress/activity cards | Home |
| `03-achievements.webp` | Achievements list (Gained / In progress / Not gained) + details panel | Steam achievements (M11) |
| `04-game-progress.webp` | Game page: round back button + big title, stat tiles, "Progress gain" area chart, hours ring | Game detail page (M7) |
| `05-search-overlay.webp` | Ctrl+K search palette over a blurred app, quick chips, category tiles | Search (M7) |
| `06-library.webp` | Library: underline sub-tabs with counts (All / Installed / Never played), filter dropdowns, search field, sort dropdown, hover shows round info + play buttons | Library usability (M7). Skip the "Platform" filter: Rocket Launcher never splits the library by launcher. |
